
## Матриця прав доступу для ролей у детективній CRM-системі

### Умовні позначення:
- ✅ — доступ дозволено
- ❌ — доступ заборонено
- ♻️ — доступ дозволено з обмеженнями (наприклад, лише до своїх об'єктів)

| Модель         | Роль        | Перегляд (📄) | Створення (➕) | Оновлення (♻️) | Видалення (🗑️) |
|----------------|-------------|----------------|----------------|------------------|------------------|
| Case           | Admin       | ✅ (усі)       | ✅             | ✅               | ✅             |
|                | Detective   | ♻️ (свої)      | ❌             | ♻️ (опис, статус)| ❌             |
| Client         | Admin       | ✅ (усі)       | ✅             | ✅               | ✅             |
|                | Detective   | ♻️ (по справі) | ❌             | ❌               | ❌             |
| Detective      | Admin       | ✅ (усі)       | ✅             | ✅               | ✅             |
|                | Detective   | ♻️ (себе)      | ❌             | ♻️ (себе)        | ❌             |
| Suspect        | Admin       | ✅ (усі)       | ✅             | ✅               | ✅             |
|                | Detective   | ♻️ (по справі) | ✅             | ♻️               | ♻️(зі справи)  |
| Evidence       | Admin       | ✅ (усі)       | ✅             | ✅               | ✅             |
|                | Detective   | ♻️ (по справі) | ✅             | ✅               | ♻️             |
| Expense        | Admin       | ✅ (усі)       | ✅             | ✅               | ✅             |
|                | Detective   | ♻️ (по справі) | ✅             | ♻️               | ❌             |
| Report         | Admin       | ✅ (усі)       | ♻️             | ✅               | ✅             |
|                | Detective   | ♻️ (свої)      | ✅             | ✅ (свої)        | ♻️ (свої).     |
| CaseType       | Admin       | ✅             | ✅             | ✅               | ✅             |
|                | Detective   | ✅ (для вибору)| ❌             | ❌               | ❌             |
| CaseSuspect    | Admin       | ✅(усі зв'язки)| ✅             | ✅               | ✅             |
|                | Detective   | ♻️ (свої)      | ✅             | ♻️               | ❌             |

### Принципи:
- **Адміністратор** має повний контроль над усіма моделями та сутностями системи.
- **Детектив** має обмежений доступ лише до об'єктів, пов'язаних зі справами, до яких він призначений.
- Доступ визначається як на рівні сервісів (`IAdminService`, `IDetectiveService`), так і через додаткові перевірки в методах (наприклад, перевірка "чи є справa у списку призначених детективу").
